Donna – Privacy policy

Last updated: October 6, 2026

Who uses Donna

Donna is a personal tool used only by its developer. It is not offered to anyone else.

What data Donna accesses

With the developer's permission, Donna has read-only access to the developer's Gmail and Google Calendar. It cannot send, change or delete email.

How the data is used

Donna uses this data only to identify commitments, deadlines, schedule changes and messages that need a reply, and to send the developer reminders and summaries. Short excerpts of new messages are sent to Anthropic's Claude API to classify them. Data is stored in the developer's own cloud account.

Sharing

Donna does not sell or share data, does not use it for advertising, and does not use it to train AI models. Donna's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account's Security settings under third-party access.
